# Logos

Brand logos for the tool tiles in setup, from [Simple Icons](https://simpleicons.org) 13.21.0 (CC0 1.0, public domain).
The marks themselves remain the trademarks of their owners and are used only to show which service a tile connects to.
They are bundled with the game and never fetched while it runs. Outlook isn't in Simple Icons, so its tile shows letters.
